# MediCare Plus 🩺📱

> [cite_start]**Your Health, Our Priority** [cite: 346]

[cite_start]**MediCare Plus** is an intuitive mobile healthcare application designed to address critical gaps in healthcare accessibility, aligned with UN **Sustainable Development Goal 3 (SDG 3): Good Health and Well-Being**[cite: 360, 367]. [cite_start]The application provides a centralized platform for managing doctor appointments, tracking medication schedules, and secure user authentication[cite: 361].

---

## 🌟 Key Features & Modules

### 1. 📅 Doctor Appointment Module
[cite_start]*(Developed by Student ID: ITBIN-2414-0014)* [cite: 322]
* [cite_start]**Browse & Select Doctors:** Search for medical specialists by specialty[cite: 323].
* [cite_start]**Real-time Booking:** Pick available dates and time slots effortlessly[cite: 323].
* [cite_start]**Appointment Confirmation:** Detailed appointment summary with cancellation options[cite: 496, 498].
* [cite_start]**CRUD Support:** Create bookings, Read doctor schedules, Update selections, and Delete (cancel) appointments[cite: 324, 325, 326].

### 2. 💊 Medicine Manager Module
[cite_start]*(Developed by Student ID: ITBIN-2414-0008)* [cite: 327]
* [cite_start]**Full CRUD Single-Screen Interface:** Add, View, Edit, and Delete medication records[cite: 301, 302].
* [cite_start]**Medication Reminders:** Record dosage times and receive scheduled intake alerts[cite: 380].
* [cite_start]**Interactive UI:** Smooth card layout with instant touch-friendly actions[cite: 305, 310].

### 3. 🔐 Authentication & Security
* [cite_start]User Registration with OTP Mobile Verification[cite: 309, 312].
* [cite_start]Secure Login with password visibility toggles[cite: 480, 483].
* [cite_start]Dark Mode & Light Mode support for accessibility[cite: 450, 466].
